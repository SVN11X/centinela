# Resultados

Una carpeta por medición, con el formato `AAAA-MM-DD-tema`. Ejemplo: `2026-12-01-p-01-arranque`.

Cada carpeta contiene:

| Archivo | Contenido |
|---|---|
| informe.md | Informe hecho con la [plantilla](../../docs/plantillas/informe-de-medicion.md) |
| datos.csv | Datos en bruto, con punto decimal |
| Fotos | Montaje e instrumentos usados |

Los resultados que no cumplen la meta también se guardan. Sirven para entender qué cambió entre una prueba y la siguiente.
