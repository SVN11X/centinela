# Placa principal

Placa propia que reemplaza al CoreS3 dentro del reloj. Se diseña en la etapa 4 con KiCad.

Versión de KiCad usada: por definir.

- [ ] Receptor GPS con su antena
- [ ] Radio LoRa SX1262 con su antena
- [ ] Gestor de batería y carga

- [ ] Conversor que sube la batería a 5 V para el módulo de IA
- [ ] Brújula y sensor de movimiento
- [ ] Barómetro
- [ ] Sensor de temperatura en la cara de la piel
- [ ] Sensor de pulso y oxígeno
- [ ] Pantalla AMOLED táctil, micrófono, parlante, linterna y vibrador

- [ ] Espacio reservado para un futuro módulo satelital ([decisión 0004](../../docs/decisiones/0004-sos-satelital-fuera-de-la-version-1-0.md))
