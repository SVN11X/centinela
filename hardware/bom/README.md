# Lista de materiales

La lista de materiales se guarda como CSV con punto decimal y estas columnas:

| Columna | Contenido |
|---|---|
| referencia | Nombre en el esquemático, por ejemplo U1 |
| componente | Descripción corta |
| fabricante | Marca del componente |
| codigo_fabricante | Código del fabricante |
| proveedor | Tienda donde se compra |
| codigo_proveedor | Código en esa tienda |
| cantidad | Unidades por reloj |
| precio_unitario_usd | Precio por unidad en dólares |
| notas | Alternativas o advertencias |

Se guarda una lista por cada versión de la placa, por ejemplo `bom-v1.csv` y `bom-v2.csv`.
