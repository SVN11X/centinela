## Objetivo

Preparar y revisar todo lo que el reloj sabe sin internet. Esta etapa puede avanzar en paralelo con la etapa 1.

## Tareas

- [ ] Definir la lista de procedimientos críticos
- [ ] Elegir una fuente oficial para cada procedimiento y registrar su licencia
- [ ] Conseguir la revisión de un profesional de salud para cada procedimiento
- [ ] Escribir las guías en español claro, en fragmentos de unas 100 palabras con su fuente
- [ ] Generar el banco de respuestas con un modelo grande, a partir de las guías
- [ ] Revisar el banco de respuestas completo, con una meta inicial de 1.000 preguntas
- [ ] Elegir la edición de Wikipedia en español: completa con imágenes (unos 37 GB) o solo texto (unos 9 GB)
- [ ] Preparar los mapas y rutas de Chile con los paquetes de Nomad Pocket o propios
- [ ] Registrar todas las fuentes y sus licencias

## Criterios de cierre

| Criterio | Cómo se comprueba |
|---|---|
| Cada procedimiento crítico tiene fuente, revisión con nombre y fecha, y versión | Revisión de cada archivo |
| El banco de respuestas está revisado completo | Registro de revisión |
| Todas las fuentes tienen una licencia compatible registrada | licencias-de-terceros.md |
