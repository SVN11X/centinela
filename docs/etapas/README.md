# Etapas

El proyecto avanza en ocho etapas. El resumen y las dependencias están en [ROADMAP.md](../../ROADMAP.md).

## Qué tiene cada etapa

Cada carpeta tiene un README con estas secciones:

| Sección | Para qué sirve |
|---|---|
| Objetivo | Qué se busca lograr |
| Entregables | Qué debe existir al final y dónde queda |
| Tareas | Lista para marcar a medida que se avanza |
| Criterios de cierre | Cómo se sabe que la etapa terminó |
| Riesgos principales | Qué podría salir mal, con enlace al registro de riesgos |
| Evidencias | Dónde se guardan los resultados |

## Reglas

1. Cada tarea de la lista se crea como issue en el hito de su etapa.
2. Una tarea se marca como hecha solo cuando su evidencia está enlazada.
3. Una etapa se cierra con la [revisión de cierre](../plantillas/revision-de-cierre-de-etapa.md), guardada en la carpeta de la etapa.
4. Si un criterio no se cumple, la revisión decide entre repetir, ajustar el diseño o cambiar el plan. Si cambia una meta o un componente, se registra una decisión.
5. Al cerrar una etapa se actualiza su estado aquí, en el README principal y en CHANGELOG.md, y se publica la versión en Releases.
