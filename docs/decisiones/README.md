# Decisiones

Aquí se registran las decisiones técnicas importantes. Cada una explica el contexto, las opciones, lo que se eligió y sus consecuencias. Este formato se conoce como ADR, registro de decisión de arquitectura.

## Cuándo registrar una decisión

- Cambia la arquitectura o un componente principal.
- Cambia la meta de un requisito.
- Hay que elegir entre opciones con costos o riesgos distintos.

## Cómo hacerlo

1. Copia [0000-plantilla.md](0000-plantilla.md) con el número siguiente.
2. Discútela en un issue con la plantilla Propuesta de decisión.
3. Al aceptarla, cambia su estado y agrégala al índice.
4. Una decisión aceptada no se borra. Si cambia, se escribe otra que la reemplaza y se indica en ambas.
