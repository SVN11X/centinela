# Glosario

| Término | Qué significa |
|---|---|
| AX630C | Chip de la marca Axera con acelerador de IA. Es el cerebro del módulo de IA del reloj. |
| ESP32-S3 | Microcontrolador de bajo consumo que maneja la parte siempre encendida del reloj. |
| Microcontrolador | Computador muy pequeño y de bajo consumo que hace tareas simples sin detenerse. |
| NPU | Parte de un chip hecha para ejecutar modelos de IA gastando poca energía. |
| Modelo de lenguaje | Programa de IA que entiende preguntas y escribe respuestas. |
| Parámetros (0,6B, 1,5B) | Tamaño de un modelo. B significa miles de millones. Un modelo más grande suele responder mejor, pero más lento. |
| Token | Pedazo de palabra. La velocidad de un modelo se mide en tokens por segundo. |
| Contexto | Cantidad de texto que el modelo puede leer de una vez, contando la pregunta y la respuesta. |
| Banco de respuestas | Preguntas frecuentes con respuestas preparadas y revisadas antes de salir. |
| Arranque | Tiempo desde que se enciende el módulo de IA hasta que puede responder. |
| LoRa | Radio de largo alcance y bajo consumo para mensajes cortos entre equipos. |
| Meshtastic | Programa abierto que usa LoRa para enviar mensajes entre equipos sin internet. |
| GPS | Sistema que calcula la posición con satélites. |
| Barómetro | Sensor de presión del aire. Sirve para calcular la altitud y anticipar cambios de clima. |
| Gestor de batería | Chip que carga la batería y reparte la energía a cada parte. |
| Interruptor electrónico | Componente que da o corta la energía de una parte del circuito por orden del microcontrolador. |
| UART | Conexión serie simple entre dos chips. |
| IP65 e IP67 | Grados de protección contra polvo y agua. IP67 resiste además una inmersión breve. |
| Lista de materiales (BOM) | Lista de cada componente con cantidad, proveedor y precio. |
| Decisión (ADR) | Documento corto que registra una decisión técnica con su contexto y sus consecuencias. |
| Hito (milestone) | Agrupa en GitHub los issues de una etapa y muestra su avance. |
| Issue | Ficha de GitHub para una tarea, una falla o una propuesta. |
| Pull request | Propuesta de cambio a los archivos, que se revisa antes de unirla. |
| Release | Versión publicada del proyecto, con sus archivos y sus cambios. |
| ZIM y Kiwix | Formato de archivo y programa para leer Wikipedia sin conexión. |
| Valhalla | Programa abierto que calcula rutas sobre mapas sin conexión. |
| Versionado semántico | Forma de numerar versiones como mayor.menor.corrección. |
| GPL, CERN-OHL y CC BY-SA | Licencias que permiten usar y modificar el proyecto si los cambios se comparten con la misma licencia. |
| NB-NTN | Comunicación celular directa con satélites. Algunos relojes la usan para enviar SOS. |
