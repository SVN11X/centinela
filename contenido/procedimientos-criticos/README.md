# Procedimientos críticos

Cada procedimiento va en su propio archivo, por ejemplo `hemorragia-grave.md`. La IA nunca genera ni modifica estos textos.

## Formato de cada archivo

| Campo | Contenido |
|---|---|
| Título | Nombre del procedimiento |
| Cuándo usarlo | Señales que indican la emergencia |
| Pasos | Numerados, una acción por paso |
| Cuándo pedir ayuda | Señales de alarma |
| Fuente | Documento oficial con enlace |
| Revisado por | Nombre y profesión |
| Fecha de revisión | AAAA-MM-DD |
| Versión | Número que sube con cada cambio |
