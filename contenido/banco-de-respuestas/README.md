# Banco de respuestas

Preguntas frecuentes con respuestas preparadas y revisadas. El reloj las muestra al instante sin encender la IA, en el nivel 1 de la [decisión 0003](../../docs/decisiones/0003-respuestas-en-tres-niveles.md).

## Formato de cada entrada

| Campo | Contenido |
|---|---|
| Pregunta | Forma principal de la pregunta |
| Variantes | Otras formas de preguntar lo mismo |
| Respuesta | Clara y corta, de 80 palabras como máximo |
| Fuente | Guía o procedimiento en que se basa |
| Revisado por | Nombre |
| Fecha de revisión | AAAA-MM-DD |

## Cómo se genera

1. Antes de salir, un modelo grande genera las entradas a partir de las guías y los procedimientos.
2. Una persona revisa cada entrada antes de que pase al reloj.
3. Como alternativa, el propio reloj puede generarlas mientras se carga, con menor calidad y la misma revisión.

Meta inicial: 1.000 preguntas.
