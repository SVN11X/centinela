# Guías

Guías de supervivencia en español claro, divididas en fragmentos que el reloj puede buscar y mostrar.

## Formato de cada fragmento

| Campo | Contenido |
|---|---|
| Título | Tema concreto, por ejemplo cómo encender fuego con lluvia |
| Texto | Unas 100 palabras, en frases cortas |
| Palabras clave | Para la búsqueda en el reloj |
| Fuente | Documento original con enlace |
| Licencia | Licencia de la fuente |

## Temas

Se definen en la etapa 2. Cada tema se registra como issue con la etiqueta etapa-2.
